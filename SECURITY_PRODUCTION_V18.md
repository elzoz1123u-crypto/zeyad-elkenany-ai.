# V18 Production Security

- HTTPS: terminate TLS at Nginx using `deploy/nginx.conf`, then set `TRUST_PROXY=1` and `FORCE_HSTS=1`.
- TURN: run Coturn using `deploy/docker-compose.turn.yml`, replace the placeholder password, expose UDP 3478 and a restricted relay range, then set TURN_URLS/TURN_USERNAME/TURN_CREDENTIAL in `.env`.
- Never commit `.env`, TURN credentials, or TLS private keys.
- Use a firewall so Node port 3000 is private/localhost only.
- Rotate TURN credentials periodically; for stronger deployments use time-limited TURN credentials generated by your TURN provider.
- Keep the 220-track catalog as links/metadata unless you have distribution rights for audio files.
